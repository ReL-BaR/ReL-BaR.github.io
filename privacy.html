Privacy policy: zumbido-backup

Last updated: 2026-10-29

zumbido-backup is a personal tool used only by its owner. It copies the owner's beekeeping notes from the owner's home server to the owner's own Google Drive.

  • Data accessed: only files and folders the tool itself created in the owner's Google Drive (Google scope drive.file). It cannot see any other Drive content.
  • Data use: files are uploaded, updated and kept as backup history. Nothing else.
  • Sharing: no data is sold, shared with or transferred to any third party. There is no analytics, advertising or tracking.
  • Storage: the Google authorization token is stored only on the owner's server. Access can be revoked at any time at myaccount.google.com/permissions.

Google API use complies with the Google API Services User Data Policy, including the Limited Use requirements.
